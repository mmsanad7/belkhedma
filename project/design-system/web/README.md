- المكوّنات الخاصة بالويب، أو التعديلات على مكوّنات الموبايل.
- فهرس الشاشات بنفس صيغة [mobile/screens-index.md](../mobile/screens-index.md).

ويُسجَّل القرار في [decisions/](../../decisions/).
