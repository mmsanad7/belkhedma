# الأيقونات والصور

## الأيقونات
صفحة Figma: [`icons`](https://www.figma.com/design/mCPCipJETTjSW7GD8vsrzY/Belkhedma-App?node-id=1-4593).

> جرد الأيقونات لم يُوثَّق بعد. راجع [status.md](../../status/status.md).

**القواعد:**
- الأيقونات توضع داخل `icon_placeholder` بالمقاسات المعتمدة: 12، 16، 24، 120.
- لون الأيقونة يأتي من token (`buttons/btn_icon`، `text/text_primary`…) وليس قيمة ثابتة.
- الأيقونات الاتجاهية (رجوع، سهم) لازم تكون معكوسة للـ RTL.

## الرسومات ثلاثية الأبعاد
أيقونات ملوّنة بألوان الهوية تُستخدم في:
- كروت الخدمات في الرئيسية (`home_services_item`): ساعة، دكتورة، مصافحة، عاملة.
- كروت الأنواع الفرعية (`service`): مطبخ، مكتب، مكنسة، غسيل، مرافقة، رعاية طبية.
- رسومات الحالات (`process_result_vectors`، `empty_state_vectors`): نجاح الحجز، نجاح الدفع، فشل الحجز، الحالة الفارغة.
