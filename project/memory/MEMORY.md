# ذاكرة الشغل

ده المكان اللي بيتحفظ فيه أي معلومة أو قرار أو تفضيل أو توصية بتطلع أثناء الشغل، علشان الشغل يكمل من أي جهاز أو جلسة أو شخص من غير ما حاجة تضيع.

## القواعد
- **أول الجلسة:** اقرأ الملف ده كله قبل أي شغل.
- **أثناء الشغل:** أي معلومة جديدة (قاعدة بيزنس، تفضيل، تصحيح، قرار، توصية، سياق) تتكتب هنا **على طول**، أياً كان مين اللي شغال (صاحب المشروع، Menna، أو أي agent)، وتترفع على `main` زي أي تعديل ([قرار 0001](../decisions/0001-push-every-change.md)).
- قرار منتج أو تصميم معتمد يتكتب برضه كـ ADR في [decisions/](../decisions/)، وهنا سطر واحد بيشاور عليه.
- لو معلومة اتغيرت، عدّل السطر القديم أو اشطبه (~~كده~~) واكتب الجديد. متسيبش معلومتين متناقضتين.
- كل سطر بتاريخه `YYYY-MM-DD`، وأحدث حاجة فوق في كل قسم.
