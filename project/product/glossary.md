# المصطلحات (Glossary)

المصطلح العربي كما يظهر في التطبيق، والمقابل المستخدم في Figma والتوثيق.

## البيزنس

| بالعربي | في Figma / الكود | المعنى |
|---|---|---|
| خدمات بالساعة | `hourly` | خدمة بعدد ساعات محدد لكل زيارة |
| خدمات الأفراد | `monthly` | عقد عاملة شهري مقسّم على زيارات |
| رعاية طبية | `medical` | تمريض ورعاية صحية منزلية |
| الوساطة | `mediation` | خدمة استقدام عاملة |
| عاملة معروفة | `well_known_maid` | مسار وساطة يحدد فيه العميل العاملة بنفسه |
| ترشيح عاملة | `maid_nomination` | مسار وساطة ترشّح فيه الشركة العاملة |
| مقدم الخدمة / الشركة | `company`، `provider` | شركة العمالة المعتمدة صاحبة العرض |
| العرض | `offer` | باقة خدمة منشورة من شركة بسعر وشروط |
| الطلب | `order` | حجز اتعمل من عرض |
| الزيارة | `visit` | تنفيذ واحد للخدمة ضمن الطلب |
| العقد | `contract` | الاتفاق بين العميل والشركة بعد تأكيد الحجز |
| طلب تواصل | `lead` | طلب يتسجّل وتتواصل الشركة بعده مع العميل، بدل الحجز الفوري |
| ضمان الاستبدال | — | شارة تعني إمكانية استبدال العاملة |
| عرض محدود | — | شارة لعرض بمدة أو كمية محدودة |
| مواد التنظيف | `cleaning_materials` | إضافة اختيارية في بعض عروض الساعة |
| الفترة | — | صباحية أو مسائية |
| كود الخصم / الكوبون | `coupon_code`، `discount` | كود يقلل السعر |
| ضريبة القيمة المضافة | VAT | 15% |
| الزائر | guest | مستخدم غير مسجّل الدخول |

## حالات الطلب

| بالعربي | في Figma |
|---|---|
| بانتظار الدفع | `waiting_payment` |
| نشط | `active` |
| أوشك على الانتهاء | `nearing_expiration` |
| ملغي | `cancelled` |

## التصميم

| المصطلح | المعنى |
|---|---|
| Atom | أصغر مكوّن (زر، شارة، أيقونة) |
| Molecule | مجموعة atoms بوظيفة واحدة (حقل بعنوان، تبويب) |
| Organism | قسم كامل من الواجهة (كرت عرض، شريط تنقل، bottom sheet) |
| Template | هيكل شاشة متكرر يُعاد استخدامه بحالات مختلفة |
| Screen | الشاشة النهائية في صفحة `screens` |
| Bottom sheet | نافذة تنبثق من أسفل الشاشة |
| Variant | حالة من حالات المكوّن (`state=active` مثلاً) |
| Primitive | متغير بقيمة خام (`primary/700 = #D72E8D`) |
| Token | متغير دلالي يشير لـ primitive (`buttons/btn_primary → primary/700`) |
